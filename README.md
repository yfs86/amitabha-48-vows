# 《無量壽經・四十八願行》完整四十八願互動版

以《佛說無量壽經》（康僧鎧譯本）**完整四十八願**為核心改編的靜心互動網頁遊戲。玩家化身為行者，漫步於極樂願海之中，尋訪 **48 種專屬光色與 8 種幾何樣式** 的願燈，透過 **「思惟 → 發願 → 莊嚴」** 三階段體驗，點亮全部四十八盞極樂願燈。

---

## 本機直接開啟遊玩（免安裝任何環境）

本專案採用**零建置（Zero-Build）純前端架構**，不需安裝 Node.js、npm 或伺服器：

1. 開啟 `amitabha-48-vows` 資料夾。
2. 直接雙擊 **`index.html`**（用 Chrome / Edge / Safari 瀏覽器開啟）即可開始遊玩！
3. 遊戲進度自動儲存在瀏覽器本機（`localStorage`），關掉重開也能接續進度。

---

## 遊戲特色

* **點哪裡、走到哪裡**：在極樂願海地圖中，滑鼠點擊或手機輕觸任意位置即可平滑走到目的地；也可使用鍵盤方向鍵 / `WASD`（`Shift` 加速）。
* **48 願全數可玩 × 獨特願燈**：收錄第 1 願至第 48 願完整原經文、白話釋義、思辨問答與現代修心啟發；每一願皆擁有**獨立色碼**並搭配 **8 種願燈幾何造型**（八瓣金蓮、千葉重蓮、六角琉璃宮燈、八芒星輪、甘露寶瓶、金色法輪、摩尼寶珠、七寶浮屠塔）。
* **呼吸光環三段完整音效**：內建 Web Audio API 合成器——**開始長按吸氣**、**放手呼氣**、以及**完整走完一個光圈**皆有對應提示音與頌缽和弦，引導身心安定。
* **四十八願星圖快速導航**：可隨時打開星圖查看六大分區進度，點擊任一願星即可直接移動前往該願燈附近。

## 如何免費上傳到 GitHub Pages 讓大家使用？

本資料夾已內含 `.nojekyll` 且無需編譯，**直接用瀏覽器拖曳上傳**就能免費上線（不需安裝 Git）：

### 步驟 1：建立獨立的 GitHub Repository
1. 登入你的 [GitHub](https://github.com/) 帳號。
2. 點右上角的 **`+` → `New repository`**。
3. **Repository name** 輸入例如 `amitabha-48-vows`（保持 **Public** 公開，免費版 GitHub Pages 需設為 Public）。
4. 直接點下方的 **`Create repository`**。

### 步驟 2：上傳 `amitabha-48-vows` 資料夾內的全部檔案
1. 在剛建好的空白倉庫頁面中，找到並點擊 **`uploading an existing file`**。
2. 打開你電腦裡的 `amitabha-48-vows` 資料夾，**全選裡面的所有項目**（包含 `index.html`、`.nojekyll`、`README.md`、`css` 資料夾、`js` 資料夾），直接拖曳進瀏覽器的上傳框。
   > ⚠️ **注意**：請確認 `index.html` 是直接位在倉庫最外層（根目錄），而不是多包了一層 `amitabha-48-vows/index.html`。
3. 等待檔案上傳完畢後，捲到下方按綠色按鈕 **`Commit changes`**。

### 步驟 3：開啟 GitHub Pages
1. 點倉庫上方選單的 **`Settings`**（設定）。
2. 點左側欄的 **`Pages`**。
3. 在 **Build and deployment** 下方：
   - **Source** 選擇 **`Deploy from a branch`**
   - **Branch** 選擇 **`main`**、旁邊資料夾選 **`/ (root)`**，然後點 **`Save`**。
4. 等待約 **1～2 分鐘**後重新整理該頁面，最上方就會出現你的公開網址：
   `https://你的GitHub帳號.github.io/amitabha-48-vows/`

把這個網址（或做成 QR Code）分享到 LINE 或社群，親友用手機或電腦點開就能直接玩！
